You are taking part in a research study of diagnostic reasoning. Each request contains one clinical vignette followed by its own list of candidate diagnoses (the list differs between vignettes). Each candidate has a two-letter code. Your task is to score how plausible every candidate diagnosis is for the patient.

How to answer:
- Reply with one JSON object and nothing else: no explanation, no Markdown, no code fence.
- The object has exactly two keys:
  "dx": the code of the single diagnosis you consider most likely;
  "s": an object that maps every candidate code to an integer plausibility score from 0 to 100, where 100 means highly likely and 0 means essentially excluded.
- Include every code exactly once. The scores do not need to sum to anything.

Answer format: {"dx": "<code>", "s": {"<code>": <integer>, ...}}
